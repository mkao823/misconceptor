Question: What is typically included in a class definition?

Instructor answer: Data members (attributes) and member functions.

## E02.Q02
<!-- chunk: ia.E02.Q02 | concepts: oop, classes, variables -->

Question: What is the difference between a data member and a local variable inside a member function?

Instructor answer: Data members can be accessed from any member functions inside the class defintion. Local variables can only be accessed inside the member function that defines them.

## E02.Q03
<!-- chunk: ia.E02.Q03 | concepts: oop, classes, functions -->

Question: What is the difference between a constructor and a function?

Instructor answer: A constructor is called whenever an object is created, whereas a function needs to be called explicitely. Constructors do not have return type, but functions have to indicate a return type.

## E02.Q04
<!-- chunk: ia.E02.Q04 | concepts: oop, classes -->

Question: When does C++ create a default constructor?

Instructor answer: If no constructor is provided, the compiler provides one by default. If a constructor is defined for a class, the compiler does not create a default constructor.

## E02.Q05

Question: How many constructors can be created for a class?

Instructor answer: Unlimited number.

## E02.Q06
<!-- chunk: ia.E02.Q06 | concepts: functions -->

Question: What is the difference between a function prototype and a function definition?

Instructor answer: A function prototype includes the function signature, i.e., the name of the function, the return type, and the parameters's type. The function definition includes the actual body of the function.

## E03.Q03

Question: How does the compiler handle inline functions?

Instructor answer: It makes a copy of the function code in every place where a function call is made.

## E03.Q04
<!-- chunk: ia.E03.Q04 | concepts: functions -->

Instructor answer: It avoids making copies of large data structures when calling functions.

## E03.Q05
<!-- chunk: ia.E03.Q05 | concepts: functions -->

Question: How are overloaded functions differentiated by the compiler?

Instructor answer: Based on the function signature. When an overloaded function is called, the compiler will find the function whose signature is closest to the given function call.

Instructor answer: If the recursion step is defined incorrectly, or if the base case is not included.

## E05.Q01
<!-- chunk: ia.E05.Q01 | concepts: sorting, insertion_sort -->

Question: In one sentence, what is the main idea implemented by insertion sort?

Instructor answer: Taking one array element at a time, from left to right, it inserts it in the right position among the already sorted elements on its left.

## E05.Q02
<!-- chunk: ia.E05.Q02 | concepts: sorting, selection_sort -->

Question: In one sentence, what is the main idea implemented by selection sort?

Instructor answer: Taking one array element at a time, from left to right, it identifies the minimum from the remaining elements and swaps it with the current element.

## E05.Q03
<!-- chunk: ia.E05.Q03 | concepts: sorting, insertion_sort, algorithm_analysis, best_case -->

Question: What is the number of operations for insertion sort under a best-case scenario, and what is the best-case scenario?

Instructor answer: N (the length of the array) operations achieved for a sorted array.

Question: What is the base case for a recursive implementation of merge sort?

## E08.Q01
<!-- chunk: ia.E08.Q01 | concepts: stacks -->

Question: What is a stack?

Instructor answer: A data structure that can store elements, which has the property that the last item added will be the first to be removed (or last-in-first-out)

## E08.Q02
<!-- chunk: ia.E08.Q02 | concepts: stacks -->

Question: What are the two main functions defined by a stack?

Instructor answer: push and pop

## E08.Q03
<!-- chunk: ia.E08.Q03 | concepts: stacks, arrays -->

Question: How can you implement a stack with an array?

Instructor answer: Keep the top of the stack toward the end of the array, so the push and pop operations will add or remove elements from the right side of the array.

## E08.Q04
<!-- chunk: ia.E08.Q04 | concepts: stacks, linked_lists -->

Question: How can you implement a stack with a list?

Instructor answer: Keep the top of the stack pointing to the head of the linked list, so the push and pop operations will add or remove elements at the beginning of the list.

## E08.Q06
<!-- chunk: ia.E08.Q06 | concepts: stacks, expressions -->

Question: How are infix expressions evaluated by computers?

Instructor answer: First, they are converted into postfix form, followed by an evaluation of the postfix expression.

## E08.Q07
<!-- chunk: ia.E08.Q07 | concepts: stacks, search -->

Question: What operations would you need to perform to find a given element on a stack?

Instructor answer: Pop all the elements and store them on another stack until the element is found, then push back all the elements on the original stack.

## E09.Q01
<!-- chunk: ia.E09.Q01 | concepts: queues -->

Question: What is a queue?

Instructor answer: A data structure that can store elements, which has the property that the last item added will be the last to be removed (or first-in-first-out).

## E09.Q02
<!-- chunk: ia.E09.Q02 | concepts: queues -->

Question: What are the two main functions defined by a queue?

Instructor answer: enqueue and dequeue

## E09.Q03
<!-- chunk: ia.E09.Q03 | concepts: queues, arrays -->

Question: How can you implement a queue with an array?

Instructor answer: Use a circular array. Keep the rear of the queue toward the end of the array, and the front toward the beginning, and allow the rear pointer to wrap around.

## E09.Q04
<!-- chunk: ia.E09.Q04 | concepts: queues, linked_lists -->

Question: How can you implement a queue with a list?

Instructor answer: Keep the rear of the queue pointing to the tail of the linked list, so the enqueue operation is done at the end of the list, and keep the front of the queue pointing to the head of the linked list, so the dequeue operation is done at the beginning of the list.

## E09.Q06
<!-- chunk: ia.E09.Q06 | concepts: queues, stacks -->

Question: What is the stack operation corresponding to the enqueue operation in queues?

Instructor answer: push

## E10.Q01
<!-- chunk: ia.E10.Q01 | concepts: trees -->

Question: What is a tree?

Instructor answer: A collection of nodes, which has a special node called root, and the rest of the nodes are partitioned into one or more disjoint sets, each set being a tree.

## E10.Q02
<!-- chunk: ia.E10.Q02 | concepts: trees, tree_height -->

Question: What is the height of a tree?

Instructor answer: The length of the longest path from the root to any of its leaves.

## E10.Q03
<!-- chunk: ia.E10.Q03 | concepts: trees -->

Question: What is a leaf?

Instructor answer: A node that has no children.

## E10.Q04
<!-- chunk: ia.E10.Q04 | concepts: trees -->

Question: What is a binary tree?

Instructor answer: A tree for which the maximum number of children per node is two.

## E10.Q05
<!-- chunk: ia.E10.Q05 | concepts: trees, bst -->

Question: What is a binary search tree?

Instructor answer: A binary tree that has the property that for any node the left child is smaller than the parent which in turn is smaller than the right child.

## E10.Q06
<!-- chunk: ia.E10.Q06 | concepts: trees, traversal -->

Question: What is the inorder traversal of a binary tree?

Instructor answer: Traverse the left subtree, then the root, then the right subtree.

## E10.Q07
<!-- chunk: ia.E10.Q07 | concepts: trees, bst, search, tree_height, algorithm_analysis -->

Question: How many comparisons does it take to find an element in a binary search tree?

Instructor answer: The height of the tree (or log of the number of elements in the tree).

Instructor answer: A walk around the tree, starting with the root, where each node is seen three times: from the left, from below, from the right.
